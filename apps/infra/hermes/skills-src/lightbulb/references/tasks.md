# Working on a Lightbulb task

Read this only when your run's instructions say you are working on one task for
this workspace. Everywhere else, the Paperclip handoffs in the other references
still hold.

On a task, Lightbulb starts, routes and reports the work. Here this replaces every
Paperclip handoff in the other references (issues, assignments, courier pattern,
`--assignee-user`, blocked-by):

- **Work for a teammate is a task, not a delegation.** When a piece belongs to
  another specialist, ask Lightbulb to start a task for it, naming them with
  `@handle` and self-contained instructions ("@finance, check the discount math").
  Lightbulb routes it and posts the result. Never assign it yourself, and do not
  ask them for the work in chat.
- **A step only a person can do** (identity checks, signatures, a phone-only
  vendor, a payment outside the rails) is a task for that person: ask Lightbulb to
  start it with the prepared text, number or amount, and say your task waits on it.
- **Software pieces** (repo, first feature, deploy, CI): ask Lightbulb to start a
  task per piece. Confirmations are approvals in Needs you; monitors are routines.
- **Notes go in this task's own room.** Lightbulb posts your result for you.
