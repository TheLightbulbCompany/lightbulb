# Prior art for an agent-driven "small software" engine CLI

Researched 2026-10-28 with WebSearch/WebFetch only. Tags: **[P]** primary (vendor docs, GitHub, YC page, press release), **[S]** secondary (press, aggregators, third-party docs mirrors), **[U]** unreachable or conflicting. Dates are page `last_updated` where shown, else access date.

## 1. What "naive" is

**Naïve (usenaive.ai), YC Spring 2025, founders Sean Dorje (CEO) and Dennis Zax (CTO), San Francisco.** Confidence: high. It is the only "naive" that is a CLI-driven cloud for agent-built apps; naive.sh and naive.dev returned nothing.

- YC page: "Autonomous Company Infrastructure… an AI research lab building autonomous companies"; free to start then pay-as-you-go [P] https://www.ycombinator.com/companies/naive (acc. 2026-10-28)
- $28.5M Series A led by Nexus Venture Partners with YC, Zetta, Liquid 2, announced 2026-08-06; article says developers use Naïve's prompts with Claude Code, Codex and Cursor [S] https://siliconangle.com/2026/08/06/naive-bags-28-5m-funding-automate-creation-day-day-running-almost-business/
- CLI: `npm i -g @usenaive-sdk/vetta-cli` ships two bin names, `naive` and `vetta`. Blueprint flow: `naive catalog`, `naive template agency`, `naive claim --key sk_live_…`, `naive up --dry-run`, `naive up`, `naive up --adopt`, `naive installs`. Blueprints declare hosted apps (`frontend_only` / `fullstack`, `deploy_dir`, optional `mcp` endpoint, secret `env`), agents (model, budget caps, cron schedules, tool policies), skills, identities, vaults. Auth: `vetta login --api-key`, `NAIVE_API_KEY` / `VETTA_API_KEY`, Bearer tokens. No `--json` documented; no MCP mentioned; an agent onboarding manifest lives at /skill.md [P] https://usenaive.ai/skill.md (acc. 2026-10-28)
- Apps primitive: "Ship a Next.js app to a real URL with Postgres, auth, and storage included"; sign-in via email/Google/GitHub; buckets with signed URLs; edge functions; apps live at `*.naive.run`; a "promote" step to production; cron priced $2.00/run [P] https://usenaive.ai/solutions/cloud-infrastructure (acc. 2026-10-28)
- Managed-agent pricing (vetta.sh): Standard $20/mo with $20 credit (7-day trial, card required), Pro $200/mo with $200 credit, prepaid USD, `vetta computer create` sandboxes [P] https://usenaive.ai/docs/getting-started/quickstart (acc. 2026-10-28)
- Not open source; resources are provisioned on Naïve's account (vendor-managed credentials in a vault), not the user's own Vercel/Supabase [P] same page. A third-party listing of $49/$149 tiers conflicts with the docs [U] https://aisotools.com/tool/naive-cloud

Other near-misses checked: a hobby project literally named **small** (`pip install small-software`, MIT, deploys private team apps to Railway with Google/Microsoft/magic-link sign-in and `small access add user@co.com`, `small mcp` for Claude Code; 0 stars, beta) [P] https://github.com/RuslanKazyradzi13/small-software (acc. 2026-10-28).
