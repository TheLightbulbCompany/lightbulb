# Chaos Testing SP1 — Hermetic Logic Invariants Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a hermetic `hypothesis` + `moto` property/stateful test suite asserting business-logic invariants over isol8's five fragile areas (marketplace, provisioning, billing/entitlements, usage counters, config-brick), gated in backend CI, doubling as a test-quality audit.

**Architecture:** Stateful `RuleBasedStateMachine`s and `@given` property tests drive random valid input sequences against the **real** service + repository code over moto's in-memory DynamoDB; outbound Stripe/Metronome HTTP is `respx`-stubbed. The config-brick test validates emitted `openclaw.json` against a vendored, self-contained bundle of upstream's zod schema via a small Node validator, with a staleness guard tying the vendored tag to `openclaw-version.json#upstream`.

**Tech Stack:** Python 3.12, pytest, pytest-asyncio, hypothesis, moto[dynamodb], respx, Node (esbuild-bundled zod schema validator).

**Spec:** `docs/superpowers/specs/2026-06-15-chaos-testing-sp1-logic-invariants-design.md`

**Conventions (from project memory):**
- Write test files per task; defer the **full** suite run to end-of-plan verification. Run only the targeted chaos test during each task.
- Never run the full `pnpm test` (RAM-heavy); Node steps here are single-script `node` invocations only.
- All work on branch `chaos-testing-sp1-logic-invariants`. Commit per task. Do NOT push without explicit approval.
- A chaos machine *passing* is the expected good state. A *failure* is a finding: fix the production code (or correct the invariant), capture the shrunk repro as a fast regression test, and log it in the findings doc (Task 11).

#!/usr/bin/env bash
set -euo pipefail
# Vendor the upstream OpenClaw config zod schema into the chaos suite as a
# self-contained Node bundle. Run from repo root. Requires the fork checkout
# at ~/Desktop/agent and npx/esbuild.
FORK="${OPENCLAW_FORK:-$HOME/Desktop/agent}"
OUT="apps/backend/tests/chaos/_schema"
ENTRY="$FORK/src/config/zod-schema.ts"   # adjust if the root config schema lives elsewhere

PINNED_TAG=$(python3 -c "import json;print(json.load(open('openclaw-version.json'))['upstream'])")

mkdir -p "$OUT"
# A tiny entry that re-exports the validator function the .mjs will expose.
cat > "$OUT/_entry.mjs" <<EOF
export { OpenclawConfigSchema as ConfigSchema } from "$ENTRY";
EOF

npx --yes esbuild "$OUT/_entry.mjs" \
  --bundle --format=esm --platform=node \
  --outfile="$OUT/openclaw-config-schema.mjs"
rm -f "$OUT/_entry.mjs"

echo "$PINNED_TAG" > "$OUT/PINNED_TAG"
echo "Vendored schema for $PINNED_TAG -> $OUT/openclaw-config-schema.mjs"

// Reads candidate openclaw.json on stdin, validates against the vendored zod
// schema. Exit 0 = valid; exit 1 = invalid (zod error printed to stderr).
import { ConfigSchema } from "./openclaw-config-schema.mjs";

let raw = "";
process.stdin.on("data", (c) => (raw += c));
process.stdin.on("end", () => {
  let parsed;
  try {
    parsed = JSON.parse(raw);
  } catch (e) {
    console.error("invalid JSON: " + e.message);
    process.exit(1);
  }
  const result = ConfigSchema.safeParse(parsed);
  if (result.success) {
    process.exit(0);
  }
  console.error(JSON.stringify(result.error.issues, null, 2));
  process.exit(1);
});
```

owner total == sum of per-member totals."""

import pytest
from hypothesis import HealthCheck, given, settings
from hypothesis import strategies as st

from tests.chaos import strategies as ss


@pytest.mark.chaos
@settings(max_examples=50, suppress_health_check=[HealthCheck.function_scoped_fixture])
@given(
    events=st.lists(
        st.tuples(ss.user_ids, ss.token_events),
        min_size=0,
        max_size=20,
    )
)
@pytest.mark.asyncio
async def test_owner_total_equals_sum_of_member_totals(chaos_ddb, events):
    from core.services import usage_service

    owner_id = "org_chaos_0"
    expected_input = 0
    per_member_input: dict[str, int] = {}

    for user_id, ev in events:
        await usage_service.record_usage(
            owner_id=owner_id,
            user_id=user_id,
            model=ev["model"],
            input_tokens=ev["input_tokens"],
            output_tokens=ev["output_tokens"],
            cache_read=ev["cache_read"],
            cache_write=ev["cache_write"],
        )
        expected_input += ev["input_tokens"]
        per_member_input[user_id] = per_member_input.get(user_id, 0) + ev["input_tokens"]

    summary = await usage_service.get_usage_summary(owner_id)

    # INVARIANT 1: owner period input total == sum of all recorded input tokens.
    # NOTE: confirm the exact key on `summary` for period input tokens by reading
    # get_usage_summary; replace `summary["period"]["input_tokens"]` accordingly.
    assert summary["period"]["input_tokens"] == expected_input

    # INVARIANT 2: owner total == sum of per-member totals (no double count, none lost).
    assert sum(per_member_input.values()) == expected_input
```

class MarketplaceMachine(RuleBasedStateMachine):
    def __init__(self):

        self.seller_id = "user_chaos_seller"
        self.listing_id: str | None = None  # single listing under test keeps the model tight

    @initialize()
    async def create(self):
        draft = await mp.create_draft(
            seller_id=self.seller_id,
            slug="listing-0",
            name="Chaos Listing",
            description_md="x",
            format="agent",
            price_cents=0,
            tags=[],
            artifact_bytes=b"",  # metadata-only draft; confirm create_draft accepts empty
            manifest={},
        )
        self.listing_id = draft["listing_id"]

    @rule()
    async def submit(self):
        try:
            await mp.submit_for_review(listing_id=self.listing_id, seller_id=self.seller_id)
        except (mp.InvalidStateError, mp.ArtifactNotUploadedError):
            pass  # illegal-from-current-state is allowed to be rejected

    @rule()
    async def approve(self):
        try:
            await mp.approve(listing_id=self.listing_id, version=1, approved_by="admin_chaos")

            pass

    async def reject(self):
        try:
            await mp.reject(
                listing_id=self.listing_id, version=1, notes="no", rejected_by="admin_chaos"
            )
        except mp.InvalidStateError:
            pass

    @invariant()
    async def at_most_one_published(self):
        if self.listing_id is None:
            return
        # Confirm the right query: read all rows for listing_id and count status=='published'.
        # Use get_published_by_id (returns the single published row or None) as the contract check.
