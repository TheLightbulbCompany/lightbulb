## 3. How the closed engines describe themselves, plus the building blocks

### Closed products
- **Lovable.** Agent Mode beta (Jun 30 2025 [P listing]; body via mirror [S]): tools = search codebase, read files, inspect logs, web search; usage-based credits vs fixed-cost Default/Chat. **Browser testing** [P docs]: "The browser runs remotely in a secure virtual environment"; screenshots, click, fill, console + network; runs against the *test* environment preview; can sign in only if the app uses the built-in backend; "if a test run is stopped, any work done during that step may be lost". **Lovable Cloud** [P docs]: "Supabase's open-source foundation"; DB + users + storage provisioned together; edge functions, jobs, secrets, logs; region fixed at enable time; per-connector permissions, "Execute backward incompatible database migrations" defaults to Never allow; migrating off is manual export/restore. Per-project vs shared Supabase topology not stated [U]. **Publish** [P]: snapshot per publish to `*.lovable.app`, "Only the current version is deployed", backend needs Run credits. **Sandbox infra**: Fly.io inferred from headers in 2024 [S]; Modal case study Jul 7 2025 [P vendor]: 15,000 → 700 lines of orchestration code, 1M+ sandboxes, 20,000 concurrent peak, 250k apps in 48 h, "encrypted Tunnel" per sandbox, snapshotting planned; Nov 25 2025 acquired **Molnett** (Firecracker microVM per container, EU) [P]. **Credits** [P]: Build-mode examples 0.5 (style change) / 0.9 / 1.2 (add auth) / 2.0 credits (landing page with images); Plan mode 1 credit; Pro credit = $0.25; agent pauses for check-in every 20 credits. **Security** [P]: Quick scan on every publish (tables without per-record access, npm criticals, unauthenticated MCP), Deep scan on demand; Wiz/Aikido add-ons.
- **Bolt.new.** WebContainers = Node.js in the browser on WebAssembly with a virtual TCP stack over Service Workers (StackBlitz 2021 post) [P]. **Bolt Cloud** [P support]: `bolt.host` hosting, "Bolt creates a database when your project needs one", auth, storage, Stripe, "server functions (also called edge functions)"; "powered by trusted platforms like Netlify and Supabase" [S/P]; Netlify was the previous default host.
- **Replit.** Agent 3 (Sep 10 2025) [P]: "runs on its own for up to 200 minutes"; App Testing on by default, periodically drives a browser, logs into Replit Auth apps; "3x faster and 10x more cost-effective than Computer Use models". Self-testing post (Dec 15 2025) [P]: problem = "Potemkin interfaces"; agent **writes Playwright code into a persistent REPL** instead of one tool call per click; gets stripped DOM with ARIA/test attributes, read-only DB queries, and logs-since-last-run; a **testing subagent** returns a summary to keep the main context (80–100k tokens) clean; autonomy 20 → 200 min; **median self-test session $0.20** vs ~$0.50 and 30–90 s for a computer-use agent filling one 5-field form. Billing [P]: "One checkpoint per request", effort-based; third-party model calls at provider rates. Deployments [P]: Autoscale / Static / Reserved VM / Scheduled; publish "saves a snapshot of your app's files and dependencies"; GCP US; "dedicated, single-tenant GCP project" per customer; filesystem not durable. Nix → image step: not documented [U].
- **v0 Platform API** (the most directly reusable closed piece). Vercel blog Jul 23 2025 [P]: "a text-to-app API that gives developers direct access to the same infrastructure powering v0.dev"; "turns v0 into a headless app builder"; `v0.chats.create({message})` returns `chat.files` + `chat.demo` (iframe-able live URL); "Create new Vercel projects, link Vercel projects to a chat, and trigger deploys"; Next.js template for your own builder. Docs [P] https://v0.app/docs/api/platform: base `https://api.v0.dev`; `GET/POST /v1/projects`, `/v1/projects/:id`, `POST /v1/chats`, `/v1/chats/:id/messages`; `v0.chats.init()` from existing files/GitHub/templates; `v0.deployments.create()` to v0 hosting (custom domains, staging/prod, logs); files ≤1,000 per chat, 3 MB each; quotas 10,000 API req/day, 1,000 chat msgs/day, 100 deployments/day, 1 GB uploads/day, 50 GitHub imports/day; SDK `v0-sdk`, `createClient({baseUrl})` for enterprise, `@v0-sdk/ai-tools`; 422 `content_policy_violation`; a "Classic v0 clone" example. Output is React/Next.js (Vue mentioned). Billing: v0 credits are token-metered [P]; Platform-API-specific pricing not documented [U]; status "beta" as of Jul 2025 [P]. Caveat: you get v0's opinionated frontend generator and hosting, not a database/auth provisioner.
- **Base44** [P docs]: MongoDB-compatible NoSQL "entities" with row- and field-level security, realtime `entities.subscribe()`; built-in auth (email, Google/MS/FB/Apple, SSO); **Deno TypeScript functions** with own HTTP endpoints, schedules, DB-event triggers, `createClientFromRequest()`, `asServiceRole`; long-lived "Actors" over WebSockets; hosting is **SPA-only** (static export, no SSR). Limits 50 functions / 5-min timeout [S].
- **Anything (Create.xyz)**: Neon as database backend [S], Postgres+auth+Stripe out of the box [S]; no architecture docs found [U].

### Agent building blocks
- **Claude Agent SDK** [P]: "a library that runs the Claude Code binary" in your process (Python/TS): file tools, bash, hooks, subagents, MCP, permissions, sessions (resume/fork), skills, plugins. Third parties may not offer claude.ai login. https://code.claude.com/docs/en/agent-sdk/overview
- **Claude Managed Agents** [P]: hosted harness, beta header `managed-agents-2026-04-01`; Agent / Environment / Session / Events; sessions run in an Anthropic cloud sandbox or a **self-hosted sandbox**; bash, file ops, web, MCP; SSE streaming, steer/interrupt; state persists server-side (not ZDR/HIPAA). $0.08 per session-hour on top of tokens [S]; self-hosted partners Cloudflare/Daytona/Modal/Vercel [S]. https://platform.claude.com/docs/en/managed-agents/overview
- **OpenAI Codex SDK** [P]: `@openai/codex-sdk` (TS) / `openai-codex` (Python) "lets your application start, continue, and resume local Codex threads"; pinned Codex CLI runtime; `startThread().run()`, `resumeThread(id)`; sandbox presets `read_only` / `workspace_write` / `full_access`. https://learn.chatgpt.com/docs/codex-sdk

### Database layer
- **Supabase Management API** [P] https://supabase.com/docs/guides/integrations/build-a-supabase-integration, /docs/reference/api/introduction: OAuth2 (`/v1/oauth/authorize`, `/v1/oauth/token`, PKCE) to act on the *user's* org, or your own org token; `POST /v1/projects` (organization-scoped; DB password not retrievable later), `/projects/{ref}/api-keys`, run query / read-only query, `POST /v1/projects/:ref/database/migrations`, deploy function, bulk create secrets; **120 req/min per user/project/endpoint**. **Supabase MCP** [P] https://supabase.com/docs/guides/getting-started/mcp: `execute_sql`, apply migration, deploy edge function, `get_advisors` (security/perf), `query_logs`, create/pause/restore project; `read_only`, `project_ref`, `features` scoping; "should not be given to customers or end users".
- **Neon** [P] https://neon.com/docs/guides/platform-integration-intro, /docs/introduction/agent-plan, /docs/neon-auth/overview: "project-per-user" via API, "Instant database provisioning (< 1 second)", scale-to-zero, per-user consumption limits, **claimable databases** (72 h to claim); Agent plan (needs Scale plan + approval): $0.106/CU-h, $0.35/GB-mo, unlimited projects, 1,000 branches/project, free org sponsored by Neon. **Neon Auth** = managed Better Auth storing users in `neon_auth` schema of the same DB; "every database branch gets its own isolated auth environment".
- **Cloudflare D1** [P] https://developers.cloudflare.com/d1/platform/limits/: 50,000 DBs/account (Paid), 10 GB each; positioned for "per-user, per-tenant" with "thousands of databases at no extra cost". **Turso**: database-per-tenant is the default pattern, Platform API; pricing sources conflict [S].

Supabase Auth (comes with the project; what Lovable/Dyad/Bolt use); Neon Auth (above); Base44 built-in; **Clerk** Platform API `/v1/platform/applications` + `clerk apps create` provision a Clerk app per tenant [S]; **WorkOS AuthKit** models tenants as Organizations, free to 1M MAU [S].

### Deploy layer
- **Workers for Platforms** [P] https://developers.cloudflare.com/cloudflare-for-platforms/workers-for-platforms/: "Each customer runs code in their own Worker"; dispatch namespaces, per-customer CPU/subrequest limits, outbound Worker for egress policy, custom hostnames via Cloudflare for SaaS; **$25/mo, 20M requests + 60M CPU-ms + 1,000 scripts included, then $0.30/M req, $0.02/M CPU-ms, $0.02/script**.
- **Vercel REST** [P]: `POST /v13/deployments`, files inline or pre-uploaded by SHA, redeploy by `deploymentId`, `QUEUED→INITIALIZING→BUILDING→READY`. **Netlify** [P] https://docs.netlify.com/api/get-started/: `POST /api/v1/sites`, digest deploy (`files: {path: sha1}` then `PUT /api/v1/deploys/{id}/files/...`) or zip; `POST /sites/{id}/ssl`; **3 deploys/min, 100/day**. **Railway** [P]: GraphQL `projectCreate`, project tokens; file upload via API weak, use CLI `railway up` [S]. ## 5. Gotchas the implementers wrote down

1. **Idle sandboxes, not builds, drive cost.** Vercel's own table: 1 vCPU/2 GB left running = $1.05/day idle, $4.09 busy, $0 stopped [P]. E2B default 2 vCPU/4 GiB ≈ $0.17/h [P]. Sprites: "sleeps when idle", ~$1/mo for a mostly-asleep app [P]. Design the lifecycle (stop on idle, wake on request) on day one; Lovable hit 20,000 concurrent sandboxes [P vendor].
2. **Long builds hit session caps.** E2B Hobby 1 h, Vercel Hobby 45 min, Pro 24 h; caps reset on pause/resume [P]. Replit's 200-min runs lean on checkpoints; Lovable pauses every 20 credits and warns that interrupting a browser test loses work [P].
3. **Supabase RLS is opt-in per table.** CVE-2025-48757: 170+ Lovable apps readable with the anon key [S]; Lovable now runs a Quick scan on every publish and defaults "backward incompatible migrations" to Never allow [P]; Dyad "generates reasonable default RLS policies, but you should review" [P]; Beam's list of what models get wrong by default: "database schema and tenant isolation, RLS, secret handling, background jobs, migrations and rollback" [P].
4. **Secrets leak into generated code.** Lovable: "API keys and other secrets cannot be stored safely in client-side code" → Secrets store + server function [P]; service_role keys found in client bundles [S]. sandboxd: "No credential ever enters a sandbox" (proxy injects on the wire) [P]; Sprites "connectors" do the same [P]; Supabase MCP runs with developer permissions, "should not be given to customers or end users" [P]; bolt.diy stores keys in browser cookies (fine locally, not multi-tenant) [P].
5. **Preview security.** Cloudflare: "AI-generated code is inherently untrusted" → per-user sandbox, outbound Worker for egress, bindings scoped per app [P]. iframe `sandbox` without `allow-same-origin`, separate origin, `postMessage` with explicit target; meta-tag CSP cannot set `frame-ancestors`/`sandbox`, use headers [S]; checking `event.source` alone is not enough [S]; VibeSDK signs branch-scoped preview URLs [P].
6. **Per-tenant isolation tiers.** Firecracker microVM (E2B, Vercel, Molnett) > Docker (sandboxd: "tighten before untrusted multi-tenancy") [P]; Workers for Platforms = one Worker + scoped bindings per app [P]; Replit gives each customer a single-tenant GCP project [P]; Neon project-per-user, D1 database-per-tenant [P].
7. **Snapshot/fork is the versioning primitive.** Vercel snapshots expire after 30 days unless configured, $0.08/GB-mo [P]; E2B paused sandboxes kept indefinitely [P]; Daytona snapshots go inactive after 2 weeks [P]; Sprites checkpoint in ~1 s [P]; Neon 1,000 branches/project and branch-isolated auth [P]. Pair a code snapshot with a DB branch or the rollback is half a rollback.
8. **Self-test in a real browser, cheaply.** Replit: write Playwright *code* in a persistent REPL rather than one tool call per click; stripped DOM with ARIA; testing subagent so the main context (80–100k tokens) stays clean; median $0.20/session vs ~$0.50 per form for computer-use [P]. Lovable uses the remote browser only after cheaper checks and cannot sign in unless the app uses its backend [P].
9. **Token cost per app (published numbers are thin).** Lovable build messages 0.5–2.0 credits (≈ $0.12–$0.50 at Pro's $0.25/credit) [P]; Replit "simple < $0.25, feature $1–3" per checkpoint [S]; v0 users report $0.50–0.70/message after token metering [S]; Managed Agents add $0.08/session-hour [S]. Budget per-turn, not per-app.
10. **Vendor SPOF.** Lovable: "Any outage would essentially take us offline"; 15,000 lines of orchestration for one provider, then 700 on Modal, then bought Molnett [P/S]. Keep a provider interface (open-lovable `lib/sandbox/factory.ts` with two providers) from the start.
