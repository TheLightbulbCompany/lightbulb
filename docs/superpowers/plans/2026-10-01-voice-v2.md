# Voice v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Siri-style floating orb + room calls ("Talk to the team"): the CEO's voice on the line, each request routed (name → Jev → CEO) to an agent that works live, several agents in parallel, relay-everything voice instructions.

**Architecture:** Backend grows a call `kind` (`dm`|`room`), a `team`, a voice agent, a per-agent turn map, server-side routing and a `room.call.changed` event; the bridge is untouched (each turn already names its agent). `@lightbulb/shared`'s `VoiceCallSession` tracks many turns at once and exposes audio levels, captions and mute. The web lifts the session into a `VoiceCallProvider` mounted once under `LiveEventsProvider`, so a floating orb survives navigation; header buttons become "Talk" / "Talk to the team"; channels show a live-caller marker.

**Tech Stack:** FastAPI + DynamoDB (boto3 resource), Jev (Vercel AI Gateway decision model), TypeScript `@lightbulb/shared` (vitest), Next.js 16 + Web Audio (vitest + Testing Library).

**Spec:** `docs/superpowers/specs/2026-10-01-voice-v2-design.md` — read it first. v1 spec: `docs/superpowers/specs/2026-09-30-voice-calls-design.md`.

## Global Constraints

- Owner rule: **CI is the test gate** — run only the test files you touch. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; PR bodies end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- Work in a fresh worktree off `origin/main` (the `docs/voice-v2-spec` branch carries this plan + spec; branch the code from it).
- **One voice per call.** DM → that agent's voice; room → the CEO's voice if the CEO is on the team, else the first team agent's.
- Voices are derived: CEO = `marin`; other agents = `VOICES[sha256(agent_id) % len(VOICES)]` with `VOICES = ("marin","cedar","quartz","ripple","vesper","willow","stone","gleam","meridian","bossa","tempo","beacon","delta","cinder")`.
- Routing order: **named agent → Jev → CEO** (→ voice agent when the team has no CEO).
- Team = the room's `kind == "agent"` members whose `listenMode != "observe"`; none → 409 `no_agents`.
- **Relay everything:** the voice answers alone only for greetings, thanks, "say that again", "hold on".
- Billing, holds, free claim, deadline, sweeper, `close_call` semantics unchanged — still **one OpenAI session per call**.
- Calls leave nothing behind; the only room-visible signal is the live marker (`room.call.changed`).
- Web colours only from tokens (`--plane-raised`, `--plane-edge`, `--fg`, `--fg-soft`, `--fg-mute`, `--live`, `--alert`); motion honours `prefers-reduced-motion`.
- Entry points: header button only — **"Talk"** (1:1 agent DM), **"Talk to the team"** (channel with ≥1 team agent). No composer mic, shortcut or hint.
- Open mic + **mute**; no push-to-talk.

```python
"""Voice-call persona: who speaks, and the relay-everything rule (spec 2026-10-01 §3)."""

from __future__ import annotations

import hashlib

VOICES = ("marin", "cedar", "quartz", "ripple", "vesper", "willow", "stone", "gleam",
          "meridian", "bossa", "tempo", "beacon", "delta", "cinder")


def voice_for(agent_id: str, ceo_id: str | None) -> str:
    if ceo_id and agent_id == ceo_id:
        return "marin"
    return VOICES[int(hashlib.sha256(agent_id.encode()).hexdigest(), 16) % len(VOICES)]


_BASE = """You are {name}, on a live voice call with a teammate. Speak naturally and briefly. Be clear and direct, not overly cheerful.

Backchannel: moderate ("mm-hm", "got it"). If interrupted, stop and listen.

Relay policy: you are the voice, not the worker. Delegate every request to the backend — any question, fact, status, task, check, change, plan or opinion about the work. Answer on your own only for greetings, thanks, "say that again", and "hold on". Never answer from your own knowledge and never guess a result. When you delegate, say in a few words that it's being handled, then wait for the result and speak it plainly."""

_ROOM = """

You speak for this team. Each request goes to the right teammate automatically:
{roster}
When a result arrives, say who it came from ("Finance says…"). If asked who is working on what, use the progress notes you were given."""


def build_persona(*, voice_name: str, team: list[dict] | None) -> str:
    persona = _BASE.format(name=voice_name)
    if team:
        roster = "\n".join(f"- {m['name']}: {m.get('card') or 'teammate'}" for m in team)
        persona += _ROOM.format(roster=roster)
    return persona
```

```python
# voice_routing.py
"""Who handles a spoken request: a name you say → Jev → CEO (spec 2026-10-01 §4)."""
from __future__ import annotations

import re

from core.services import jev

_LEAD = r"^(?:hey|ok|okay|so)?[\s,]*"
_VERB = r"\b(?:ask|tell|get|have)\s+"


def named_agent(text: str, team: list[dict]) -> str | None:
    t = text.strip().lower()
    for m in team:
        name = re.escape(m["name"].lower())
        if re.match(_LEAD + name + r"\b", t) or re.search(_VERB + name + r"\b", t):
            return m["id"]
    return None


async def pick(owner_id: str, call: dict, utterance: str, transcript: str, ceo_id: str | None) -> str:
    team = call.get("team") or []
    if call.get("kind") != "room":
        return call["voiceAgentId"]
    ids = {m["id"] for m in team}
    named = named_agent(utterance, team)
    if named:
        return named
    chosen = await jev.pick_agent(owner_id, room_name=call.get("roomName") or "", team=team, text=utterance, recent=transcript)
    if chosen in ids:
        return chosen
    return ceo_id if ceo_id in ids else call["voiceAgentId"]
```

```python
async def pick_agent(owner_id: str, *, room_name: str, team: list[dict], text: str, recent: str) -> str | None:
    """One agent from `team` for a spoken request, or None when unsure/unavailable. Never raises."""
    try:
        cards = await asyncio.gather(*(agent_card(owner_id, m["id"], m["name"]) for m in team))
        criteria = {m["id"]: card for m, card in zip(team, cards)}
        state = {"room": {"kind": "channel", "name": room_name},
                 "recent": [{"author": "transcript", "text": _clip(recent, 1500)}] if recent else [],
                 "latest": {"author": "caller", "text": _clip(text, 1000)}}
        answers = await decide(state, {"who": {"type": "choice", "instructions": WHO_INSTRUCTIONS, "criteria": criteria}})
        if not isinstance(answers, dict):
            return None
        who = answers.get("who") or {}
        choice, probs = who.get("choice"), who.get("probabilities") or {}
        return choice if choice in criteria and float(probs.get(choice, 0)) >= CONFIDENT_P else None
    except Exception:  # noqa: BLE001 -- routing must never fail a turn
        logger.warning("jev pick_agent failed", exc_info=True)
```

```python
async def _claim_turn(call_id: str, agent_id: str, run_id: str, seq: int) -> str | None:
    """Make run_id this agent's turn if seq is newer than that agent's holder. Returns the old run id."""
    resp = await run_in_thread(
        _table().update_item, Key=_key(call_id),
        UpdateExpression="SET turns.#a = :t",
        ConditionExpression="#s = :open AND (attribute_not_exists(turns.#a) OR turns.#a.seq < :seq)",
        ExpressionAttributeNames={"#s": "status", "#a": agent_id},
        ExpressionAttributeValues={":t": {"runId": run_id, "seq": seq}, ":seq": seq, ":open": OPEN},
        ReturnValues="ALL_OLD",
    )
    return (((resp.get("Attributes") or {}).get("turns") or {}).get(agent_id) or {}).get("runId")


def _identity(call: dict, run_id: str, agent_id: str) -> dict:
    # Must equal the bridge's turn.call_session_key: one Hermes session per (call, agent).
    return {"runId": run_id, "companyId": call["companyId"], "agentId": agent_id, "callId": call["callId"],
            "sessionId": f"agent:{agent_id}:lightbulb:call:{call['callId']}"}


async def _stop_turn(call: dict, agent_id: str, run_id: str | None) -> None:
    if not run_id:
        return
    try:
        await _runtime(call, f"{_BRIDGE_RUNS}/{run_id}/stop", {"identity": _identity(call, run_id, agent_id)}, timeout_s=10.0)
    except Exception:  # noqa: BLE001 -- a turn we can't stop finishes; its frames are dropped client-side
        logger.info("voice turn stop failed", exc_info=True)


async def _stop_all_turns(call: dict) -> None:
    for agent_id, t in (call.get("turns") or {}).items():
```
