Keep exactly one record for each entity and attribute. A new statement about a slot that already has a record updates that record; it never adds a second one. Keep the speaker's name in the record text.

When a value changes (the speaker says it changed, moved, is now different, or replaces an earlier value), rewrite the record as:
`<current value> (since <date>; was <old value>, <who>, until <date>)`
Dates are YYYY-MM-DD. If the record already has history, keep it after the first "was", oldest last.

When two people give different values for the same slot and neither says anything is changing, do not choose one. Rewrite the record as:
`Contested: <v1> (<who>, <date>) vs <v2> (<who>, <date>)`
When one of them later confirms or changes their value, resolve it with the "since" form above.

Write the status and the dates into the record text in exactly these forms. They are read back from the text later, so do not paraphrase them. Never rename or drop the AddMemory and UpdateMemory operations; only change the text you write into them.
