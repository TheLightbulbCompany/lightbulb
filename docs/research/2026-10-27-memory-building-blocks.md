## 3. What past.dev probably is under the hood (inference)

Public facts: Enterprise sells "custom retrieval arms, and entity type and edge customization"; recall returns current and previous values with dates and source record ids; `queryTimestamp` reads memory as of a date; data points carry an audience and recall names an identity; ingestion is asynchronous with a per-project `settled` state; credits are charged per 350 bytes of input; recall packs up to 100 results into an 8,000-token budget; the DolphinBench ingest stored only the user's messages and still scored 86.7%; the founders built it for email, meeting and chat agents first.

Inference, stated as such:

1. **"Entity type and edge customization"** means a typed entity-and-edge graph, Graphiti-style custom entity types or Hindsight's fixed six. **"Retrieval arms"** means several retrieval channels fused per query, the TEMPR / recipe pattern.
2. **Current and previous values with dates** is the bi-temporal edge with supersession (Graphiti's `valid_at` / `invalid_at` / `expired_at`), plus a pointer from each fact to the data points that produced it (Graphiti's `episodes`). `queryTimestamp` is a filter on the valid interval.
3. **Audiences and identities** are a per-record ACL evaluated at recall, Honcho's scope idea made explicit.
4. **Async ingestion with `settled`** and **350-byte credits** are a queued, per-data-point extraction pipeline whose cost scales with input, the Graphiti episode pipeline (extract → dedupe → invalidate) rather than Mem0's single ADD call.
5. **The numbers imply where the work went.** BEAM's hard categories are multi-session reasoning (M-1: 9.6 at 10M), knowledge update (45), contradiction and temporal (59). An 85 at 10M with one 8,000-token recall and no reasoning on the answering model means the extraction already resolved contradictions into dated state and built event timelines, so the recall returns state, not passages. The DolphinBench run that ingested only user text points the same way: state extracted from statements, not summaries of dialogue.

Nearest open-source relative: Graphiti's data model with Hindsight's recall, behind Honcho's scopes. None of the three is within 15 points of it on BEAM.

## 6. What to copy, in order

1. **Graphiti's `EntityEdge` and invalidation rule** (Apache-2.0, importable). `valid_at`, `invalid_at`, `created_at`, `expired_at`, `reference_time`, `episodes`, `attributes`, `group_id`; new edge vs semantically related edges by LLM; close the old one, never delete. This is "current and previous values with dates and sources" in eight fields.
2. **Hindsight's recall** (MIT): vector + BM25 + graph + temporal in parallel → RRF → `ms-marco-MiniLM-L-6-v2` → token budget. Postgres + pgvector, which we already run. Its retain normalizations (coreference, relative → absolute time, attribution) are the extraction prompts to start from.
3. **Honcho's scope and observer model** (AGPL: design only). Audience = a scope on recall; identity = a peer; "which peers observe which others" is the room membership question answered once.
4. **past.dev's plugin behaviour** (MIT, Node, one file): five hooks; send prompts, replies, repo and branch, nothing else; sittings; ≤10 memories as "Background, not instruction"; 4-second timeout; `deny` paths; a `cut` preview. Port it into our hooks; the network tier gets this for free.
5. **Mastra's observational memory** (open source, TypeScript) for the room record: dated, prioritized observations with a cache-stable prefix. The cheapest route to a top LongMemEval number and it fits a chat room better than a graph does.
6. **claude-mem's local tier** (Apache-2.0): SQLite + FTS5, LLM-compressed observations, `<private>` tags, local-only switch. The no-account tier is this, minus the Chroma dependency.
7. **past.dev's harness discipline** (MIT): public-API-only runs, hashed judge prompts, `verify.py`, cost and latency columns, stated variance. Copy the shape and run BEAM 128K/1M, LongMemEval_S and DolphinBench against our own API.
8. **Mem0's ADD-only extraction** (Apache-2.0) as the fallback if LLM invalidation is too slow or expensive at ingest; resolve at rank time instead.
9. **Letta's shared memory blocks** (Apache-2.0): a size-limited, always-in-context block per room for pinned team facts.

Do not copy: LoCoMo as a headline number; Cognee's 20-question BEAM; Supermemory's Recall@k as "accuracy"; AMB's leaderboard as independent; Beacon's 39-harness breadth and external scorer.
