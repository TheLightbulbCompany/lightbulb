# Frontend font assets

`satoshi-variable.woff2` is the official, unmodified Satoshi variable webfont
distributed by [Fontshare](https://www.fontshare.com/fonts/satoshi) under the
[ITF Free Font License](https://www.fontshare.com/licenses/itf-ffl). It is
self-hosted here so the app makes no runtime request to a third-party font CDN.
