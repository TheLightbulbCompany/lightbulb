## Where Lightbulb is behind

- Retrieval depth. Shipped free-network search is a local keyword search; past.dev runs a five-stage pipeline and Lightbulb's workspace version (expansion, fusion, rerank) is pending and untested. [PH §1, PR]
- No published benchmark. past.dev has BEAM numbers with a public harness; Lightbulb has none, and the workspace target (10M, 85.03) has not been run. [PD §4, SP §8]
- No as-of query on the shipped path; past.dev has `queryTimestamp`. [CLI usage.md, PD §2]
- Memory extraction on the free network depends on the agent choosing to call `remember`; the spec says to measure how often that happens and nudge if low. past.dev extracts automatically. [SP §4.2]
- Session-start memory reaches only Claude Code and Codex; Cursor, Grok CLI and OpenCode must call `recall`. [CLI usage.md]
- Five harnesses against Beacon's 29 runtimes and past.dev's plugins for four plus Hermes. [CLI agents.md, BP §3]
- Reason Network has more harness delivery paths (Command Code, DeepSeek Harness, Hermes, ZCode, Amp by hand) and a hosted-assistant MCP endpoint live; Lightbulb's equivalent runs through the workspace. [RN-now, P2P item 12]
- Workspace engine is unmerged and undeployed; the strategy change replaces the AgentCore strategy and needs a dev import first. [PR]

## Where Lightbulb is ahead

- Only one with memory that crosses people with no server: `team` entries replicate between member computers. Beacon is per project/account, Reason Network has no memory, past.dev needs its hosted service. [CLI usage.md, BP §1, RN-now]
- Memory and messaging in one install; Beacon has no live agent path and past.dev and Reason Network each do one half. [BP §4, PD, RN-now]
- Contested facts are shown with both sides, names and dates; past.dev has no contested state and its own pages carry duplicate current claims. [CLI usage.md, PH §2]
- Nothing leaves the computer unless signed in and chosen; Beacon Cloud is preselected in its installer with a 30-day backfill. [CLI security.md, BP §4]
- Approval gate with no third-party scorer: evaluator output is text a person approves, from Lightbulb's side; Beacon's evaluator sends a projection to TypeSafe or SubQ and returns probabilities only. [CLI security.md, BP §1]
- Secrets refused rather than scrubbed, before they enter a replicated log. [CLI security.md]
- Forget reaches every member computer, and any member can forget a team entry. [CLI security.md]
- Capture never records prompts or output, only tool-call summaries of at most 200 chars; past.dev sends prompt and reply prose. [CLI security.md, MP §3]
